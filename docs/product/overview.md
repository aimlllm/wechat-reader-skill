# 产品范围

让使用者把通用 skill 交给本机 Codex 或 Claude Code，在自己的 Mac 上准备微信只读访问。流程：检查已有接入 → 准备工具和 profile → 必要时取钥 → 全库验证 → 选择会话 → 真实读取 → 说明覆盖。

- R1：同一 SKILL.md 支持两种本地代理，README 提供安装位置和可复制准备请求。
- R2：优先复用有效密钥，准确选择账号和会话，按有界时间完整分页。
- R3：全库验证和真实消息均成功才报告就绪；失败与空结果区分。
- R4：取钥保留 SIP 和正式微信原签名，只用核验过的私有副本；密码和手机确认由本人完成。
- R5：新建 Git 历史只包含通用文档、代码与合成测试，真实运行资料全部外置。
- R6：代理只接收必要安全字段，未知 payload 和媒体认证资料不原样输出。

不包含一键安装、微信发送、自动回复、常驻服务、完整朋友圈、全媒体解码或手机未同步历史。其他机器的成功需当地验证，合成测试不能替代。项目没有独立界面。
