# 技术合同

主技能在 skills/wechat-reader-portable/。Python3.10+ 标准库包装独立安装的 GreenBubbles，不分发第三方二进制；版本与工具指纹留在使用者外部私有记录中。

## 查询

profile 明确指定一个账号的数据根、凭据、查询和验证工具及其 SHA-256。程序拒绝包内运行资料、符号链接、不安全权限和校验不符的工具，只经 stdin 传入凭据。诊断仅返回固定类别和数量。默认安全投影保留必要身份、文本、分页、来源与覆盖标记，未知和原始内容不直出。

live 读取保留 SQLite 锁与 WAL 处理，不用 immutable=1。跨库和跨页不是同一时刻快照；重复分析需正确取得一致快照或保存有界解析记录。

## 恢复

capture_filtered.py 核验系统保护、正式与私有应用指纹、调用者和进程路径、PBKDF参数、目标salt和候选HMAC，最多300秒后脱离。它不准备、签名、启动或关闭应用；这些步骤由部署代理按参考文档独立执行和验证。

## 验证与整合

公开版本来自经过审阅的完整文件快照，不包含旧私有仓库或开发过程的提交链。测试只用合成 fixtures，不读真实账号。公开前核对可达历史、暂存区、受控文件和中性提交身份；后续维护同样执行检查。

每次真实部署仍需全库验证、指定会话消息证明与捕获后清理。测试、远端保存和匿名公开读取分别验收。
