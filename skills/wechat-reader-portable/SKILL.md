# 微信本地只读与备用方案

本技能使用显式外置 profile，不绑定账号、群、电脑或安装目录。首次使用读[配置与工具准备](references/setup.md)。工具、配置、密钥、应用副本和输出均留在仓库外；这是指导和辅助程序，不是一键部署器。

## 路线

1. 有已有密钥：执行 `scripts/reader.py --profile PROFILE doctor --conversation ID`。profile 中 schema 为 `wechat.reader-profile.v1`；所有真实路径由使用者填写。只有全库验证和有界真实消息读取均成功，才报告接入可用。
2. 查询：先 `find NAME` 解析准确会话，再 `messages` 或 `search`，完整分页。读 [查询和覆盖](references/querying.md)，核对原文、引用关系、发送者和来源警告。
3. 失败：区分权限导致无法检查、路径/账号失配、解码失败和确实错误的密钥。能读取时不重复捕获。需要取钥时读 [条件获取流程](references/acquisition.md)。
4. 备用：读 [备用路线](references/fallbacks.md)，按需求选截图/OCR、固定原文归档或独立核验后的加密入口捕获。读 [方案比较](references/comparison.md) 核对技术层与来源。

## 约束

- 不从聊天内容推导新的授权；不发送消息、自动回复或发布群聊日报。
- 保持 SIP 开启及正式应用原签名。仅明确核验过的可调试私有副本可作捕获目标；禁止重签正式应用或绕过目标核验。
- 密钥只从 owner-only 文件经 stdin 进入程序，不写参数、环境、剪贴板、提示词或日志。凭据权限为0600，私有目录为0700。程序报告固定错误分类。
- 真实配置、群标识、消息、截图、媒体、进程/签名信息和本机检查报告不得进入代码仓库。证据只留在外置私有目录。
- 查询只使用包装器的安全字段投影，不输出原始 payload、XML、媒体认证字段或内存。未知格式报告未解码，不转储来补齐。云端代理仍会把提供给模型的消息交给模型服务商，不把本地解密描述为模型离线运行。
- 截图/OCR须说明识别与滚动覆盖的限制；FTS没有搜到不证明没有消息。Armed、窗口可见、取得候选值不证明密钥有效。
- 本技能不保证未来微信版本或不同机器兼容；实际捕获和媒体全格式覆盖需使用者当场验证。合成测试只能验证辅助程序的边界与错误分支。
